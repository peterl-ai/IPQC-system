# Reference Materials

Raw GQMS screenshots, exported patrol-standard templates, and sample inspection reports are internal reference artifacts.

Keep raw files locally under:

```text
reference/private/
```

`reference/private/` is ignored by Git and should not be pushed to a public repository.

Examples currently used as design references:
- Patrol Standard exported Excel template
- Legacy GQMS inspection report Excel
- Legacy GQMS web screenshots
- Galaxy Tab A7 / Android 11 device screenshots
